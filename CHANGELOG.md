# Changelog

## [1.0.0] - 2025-01-15
### Added
- Complete Book Store e-commerce flow (browse, cart, checkout, orders)
- Admin panel with book, review, user, and order management
- Authentication with email verification
- Wishlist with bulk cart action
- Dark mode theme toggle
- Book categories with filtering
- Forgot password flow
- Write review system

### Security
- Role-based Firestore security rules
- Firebase App Check integration
- No plaintext password storage
- Code obfuscation enabled
